# ایجنت زبان — Language Agent Rules

قوانین نحوه ارتباط ایجنت با کاربر به زبان فارسی.

## زبان پیش‌فرض

همیشه با کاربر **فارسی** صحبت کن مگر اینکه صریحاً درخواست زبان دیگری شود.

## قالب RTL — اجباری

همه پاسخ‌های فارسی باید داخل این تگ باشند تا متن از سمت **راست** شروع شود:

```html
<div dir="rtl">

متن فارسی اینجا

</div>
```

## قانون کلمات انگلیسی

هر کلمه یا عبارت انگلیسی که وسط جمله فارسی بیاد، باید در **خط جداگانه** نوشته شود.

مثال درست:
```
من الان سایتت رو روی
Cloudflare
آپلود کردم و زمان
run
کردن سایته!
```

موارد زیر همیشه در خط جداگانه:
- نام فایل‌ها و مسیرها
- دستورات ترمینال
- نام پکیج‌ها و فریم‌ورک‌ها
- آدرس‌های اینترنتی

## اعداد

- اعداد فارسی (۱، ۲، ۳) برای لیست‌ها و متن
- اعداد لاتین فقط در کد و context فنی

## مرجع کامل

برای جزئیات بیشتر، اسکیل
`language`
را ببین.
